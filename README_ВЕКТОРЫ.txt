ВЕКТОРНЫЙ КОНВЕРТЕР PDF И SVG ДЛЯ LIGHTBURN (Windows)

Запустите «ЗАПУСТИТЬ ПРОГРАММУ.bat» и выберите PDF или SVG, либо выполните:
  python vector_convert.py "файл.svg"

Нужен Python и PyMuPDF: python -m pip install pymupdf
Результат: рядом с PDF папка с суффиксом _vectors; SVG, векторный PDF и PNG.
SVG и PDF состоят из замкнутых векторных контуров без толстых обводок;
PNG — обычное изображение. Исходник не изменяется. Толстые линии переводятся
в границы средствами Windows WPF, объекты объединяются/вычитаются в исходном
порядке. Чёрный фон PDF становится прозрачным/белым, белые дорожки — чёрными.
Размер страницы сохраняется; после импорта в LightBurn обязательно проверьте
известный размер и отверстия. Для резки векторные границы могут давать проходы
по внутренним и внешним контурам — проверьте предпросмотр перед запуском.

По умолчанию допуск приближения векторных кривых 0.01 pt (около 0.0035 мм).
Кривые и границы представлены множеством коротких прямых: без растеризации,
но геометрия приближённая. PNG формируется с 600 DPI, настройка --dpi 1200.
Другие параметры: --page 1, --tolerance 0.005, -o папка.
PNG может импортироваться без учёта DPI, выставляйте размер вручную.

Ограничения: чёрно-белые непрозрачные PDF и SVG с векторной геометрией без текста,
растровых картинок, обрезок и групп; линии только сплошные со скруглёнными
концами и соединениями. Такой набор есть в проверенном файле платы. Для других
PDF конвертер может остановиться с сообщением об ограничении. Важно: белые
фигуры считаются дорожками, чёрные — вырезами; для PDF с обычной чёрной
графикой на белом фоне этот алгоритм не подходит.
